# Submarine Port

Port em JavaScript do clássico jogo **Submarine**, originalmente desenvolvido
pela JikeSoft para JavaME.

## 💻 Informações

O projeto busca portar o jogo de forma **fiel ao original**, mas **algumas
coisas podem não estar 100% iguais**.

## 👨‍🏫 Testando

Você pode testar como ficou
[clicando aqui](https://jncjcoder.github.io/submarine-port/index.html).

## 🎮 Controles

PC:

- **Seta para Cima (↑)**: mover para cima (Seleção)
- **Seta para Baixo (↓)**: mover para baixo (Seleção)
- **Enter**: ação principal / selecionar
- **P**: pausar o jogo

Mobile:

> 🚩 Movimento nos menus ainda não implementado, apenas ação principal.

- **Toque na tela**: ação principal / selecionar (equivalente ao Enter)
